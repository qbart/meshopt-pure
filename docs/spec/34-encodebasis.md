# 34 — encodebasis (`gltf/encodebasis.cpp`, KTX2 via BasisU)

`gltfpack/src/encodebasis.rs`, used for `-tc`/`-tu` (+ `-tq`, `-ts`, `-tl`, `-tp`, `-tfy`, `-tj`). Output must be
byte-identical to C++ gltfpack built with `WITH_BASISU` against KTX-Software@2e690dd (basisu 2.10).

## Split of work
C++ hands each image to `basis_compressor` with `m_create_ktx2_file`. The `ktx` crate (`qbart/ktx-rs`) ports the
compressor core (ETC1S frontend/backend, UASTC LDR 4x4 + RDO) but not the file-level features, so these are
ported here from basisu 2.10:
- source loading (`load_png` → `ktx::lodepng::lodepng_decode32`, `load_jpg` → `ktx::jpgd` with linear chroma
  filtering, 4 components); `has_alpha` is decided on the decoded file (any `a < 255`), before flip/resample;
- `m_y_flip` (row swap), `m_resample_width/height` (`image_resample`, box filter, `perceptual` sRGB, clamp; the
  return value is ignored like C++, equal size → copy);
- `generate_mipmaps` (kaiser, wrapping, `m_mip_fast`, `m_mip_srgb`, `has_alpha ? 4 : 3` components, new images black
  with alpha 255; levels down to 1x1);
- `create_ktx2_file` + `get_dfd` (LDR ETC1S/UASTC 4x4 only): DFD tables with transfer function and UASTC channel
  fix-ups, KVD `KTXwriter=Basis Universal 2.10`, ETC1S SGD (BasisLZ), UASTC zstd level 9 (`zstd-pure-rs`, a
  translation of libzstd 1.5.7, the version bundled with basisu), levels written smallest first.

Mip levels are passed to `BasisCompressor` as separate source images: for a 2D texture the encoded slice data is
the same, and the KTX2 file is rebuilt from the `.basis` output (slice descs, codebooks, Huffman tables). Alpha is
forced from the source file decision (`force_alpha` / `check_for_alpha = false`).

## gltfpack mapping
- `kBasisSettings[quality - 1]`; UASTC: pack level, RDO if `q > 0`, dict 1024; ETC1S: compression level,
  quality level, no endpoint/selector RDO for normal maps. `perceptual`, `mip_srgb`, transfer function = `info.srgb`.
- Images that are not PNG/JPEG are left as is; errors: `error reading source file`, `error parsing image header`,
  `error decoding source image`, `error encoding image`. No temporary files (C++ writes/reads them).
- `basis_parallel_compress`: images are spread over `-tj` (or available parallelism) threads, every compressor
  uses a single threaded job pool, so the output does not depend on the thread count.

## Divergences
- basisu reads PNGs with `pv_png`, the port with lodepng; outputs agree on the tested formats (all color types,
  1-16 bits, tRNS, Adam7) but invalid PNGs may be rejected differently.
- C++ built without `NDEBUG` asserts in `sanity_check_input_params` when an image is skipped; release builds (and
  the port) skip it.

## Verification
- Golden cases `*.tc*`/`*.tu*` in `gltfpack/tests/data/cases.txt` (repo models + `synthetic/tex`, PNG edge cases
  generated by `synthetic/tex/gen.py`), expected outputs from `gen-golden.sh` (BasisU reference build).
- Out of repo: 16 textured sample models x 12 option sets identical to the C++ BasisU build.
